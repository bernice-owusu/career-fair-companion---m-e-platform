# Career Fair Companion & M&E Platform

Mobile-first PWA for career fair registration, booth tracking, reflections, exit surveys, and M&E analytics synced to Google Sheets via a Google Apps Script webhook.

- **Students' Fair** (Monday): walk-in registration, questions, post-event survey.
- **Professionals' Fair** (Friday): pre-registration with code + QR, code check-in, booth tracking, tickets, exit survey.
- **M&E admin** at `/mneadmin` (default passcode `mne2026`): live dashboards, webhook config, and Google Sheets sync.

## Stack

- React + Vite + TypeScript, Tailwind CSS v4 (`@tailwindcss/vite`), no routing library
- All state lives in `localStorage` (`kcf_*` keys); sheets sync is a `no-cors` webhook to a deployed Apps Script web app
- The full Apps Script source is generated by `GoogleSheetsService.getAppsScriptCode()` (shown in M&E admin)

## Commands

- `npm run dev` — Vite dev server on port 3000
- `npm run build` — Production build (Vite)
- `npm run lint` — Type-check only (`tsc --noEmit`)
- `npm run clean` — Removes `dist/` and `server.js` (uses `rm -rf`; on Windows run in PowerShell/git-bash)

## Setup

No env vars are required. Optional: `DISABLE_HMR=true` (in `.env.local`) switches the dev server to skip HMR/file watching.

To enable Google Sheets sync:

1. Open your spreadsheet → Extensions → Apps Script, and replace `Code.gs` with the script copied from **M&E admin → Google Sheets tab**.
2. Deploy → New deployment → **Web app**, *Execute as: Me*, *Who has access: Anyone*.
3. Paste the returned Web App URL in **M&E admin → Google Sheets tab → Save URL**.
